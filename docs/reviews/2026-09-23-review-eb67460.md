# Review of M8–M12 (0.6.0) at commit eb67460

Date: 2026-09-23. Scope: commits `5ceeb50..eb67460`: the property kernel, authoring commands, checker, registry, other property shapes, and the 0.6.0 docs. Line numbers refer to `eb67460`.

## Summary

Every CI step passes locally. The kernel and most of the new theorems are sound and meaningful. The problems fall into three groups:

- **Two headline guarantees are weaker than stated.** `allValid` relies on a runtime guard for updates. `NIPackage` can be satisfied vacuously.
- **Two tool bugs can mislead users.** `#check_invariant` ignores initial worlds that violate the invariant. `preserves` can attach its hypothesis to the wrong argument.
- **Registry metadata isn't tied to the proofs,** and the `unproved` clause cannot be parsed.

Nothing here is pushed yet: `main` is 12 commits ahead of `origin/main`, and there is no `v0.6.0` tag.

## High

### H1. `allValid`: update validity still comes from the runtime guard

**Where:** `examples/private-games/PrivateGames/Model/Invariants.lean:57-59,146-148,185`, `Model/Step.lean:68-69`.

The statement is sound: every reachable model world has only `Valid` games.

- **Inserts** are covered by a genuine domain fact (`openGame_valid`).
- **Updates** are not:
  - The app obligation `WriteOk (.updateGame old new)` only requires `new.id = old.id`.
  - `Valid new` comes from `commitOk`'s runtime `Valid.holdsB new` check.
  - The store's `apply` also accepts only valid games.

The dependency closure of `allValid` does not include `decide_valid`, `playMove_valid`, `resign_valid`, or the `preserves`-generated theorems.

Counterexample: the scratch lemma `writeOk_admits_invalid` shows an update allowed by `WriteOk` whose result is not `Valid`. So a `playMove` that produced invalid games would leave `allValid` proved; those writes would just be refused at runtime.

**Overstated in:** decision 0016:24-28, and PLAN.md:340 ("entity invariant plus the `preserves` obligations gives the system invariant").

**Fix:**
1. Strengthen `WriteOk` for updates to require `Valid new`. Discharge it in `decideCore_writeOk` from the `preserves`-generated theorems, which in turn need `Valid old` from the loaded slice.
2. Keep the runtime guard as defense in depth.
3. Optionally prove the guard's validity check never fails on anything `core` plans.

### H2. `NIPackage` does not prevent vacuity

**Where:** `LeanApi/Props/Shapes.lean:170-173,319-327`; decision 0019:31-36.

`vacuousPkg : NIPackage gamesSys gamesObs` compiles with no hypotheses. It sets:
- `acts := False`: no request is covered;
- `enabledPre := True` and `enabledOk := True`: "availability" is trivially satisfied.

Neither of the package's guards against vacuity constrains `acts`. The `Enabled` component isn't tied to the observer or to `acts`, so "deny everything cannot supply `enabled`" is false.

A second problem: the `Hidden` witness uses `emptyWorld`, which has no sessions. No request can authenticate there (`hidden_witness_no_actor`), so the witness sits exactly where noninterference is trivial.

**Fix:**
- `Hidden` should require an acting request (`acts a r w₁` for some `r`).
- `Enabled`'s precondition and result should be stated in terms of `acts` and the observation.
- `gamesNI` should discharge `ReadsOwn` satisfiability instead of taking it as a hypothesis.

### H3. `#check_invariant` reports "✓ inductive" when an initial world violates the invariant

**Where:** `LeanApi/Props/Check.lean:119-149`.

The checker only looks for *one* initial world satisfying `I`. It never checks that *every* initial world satisfies `I`, which `Inductive` requires.

Reproduction (`Chk3.lean`): initial worlds 0 and 1, invariant `n % 2 = 0`. The output is `✓ satisfiable … ✓ inductive within the bound`, but the invariant is false in initial world 1.

**Fix:** report every enumerated initial world that violates `I` as a failure of the invariant itself.

### H4. `preserves` can attach the hypothesis to the wrong argument

**Where:** `LeanApi/Props/Authoring.lean:335-337` (`preservesType` keeps the *last* argument of the carrier type).

When the carrier is a common type, the generated theorem can be true while the function does not preserve the invariant. Reproduction (`Pres8.lean`):

```lean
invariant Small (n : Nat) where
  lt : n < 10
def setTo (s : Nat) (k : Nat) : Except String Nat := .ok k
preserves Small by setTo
-- generated: ∀ s k s', Small k → setTo s k = .ok s' → Small s'
-- yet Small 3, setTo 3 50 = .ok 50, ¬ Small 50
```

The generated statement is correct for structure carriers with one state argument, which covers README and private-games.

**Fix:** refuse a decision with several arguments of the carrier type unless the state argument is named explicitly (`preserves I by setTo (state := s)`).

### H5. Registry coverage metadata is author-chosen and never checked

**Where:** `LeanApi/Props/Registry.lean:161-171`.

`register_invariant … covers` is a string list the author writes. So are `touches` and the tables each writer declares. None of them is tied to the system the theorem is about.

Reproductions (`Reg1.lean`):
- **A forged claim shows as Proved.** `register_invariant "Every stored game is Valid (forged)" by Nat.add_comm touches "games" covers provedWriters ++ ["adminResetGame"]` is displayed as **Proved**, and coverage accepts `adminResetGame`.
- **A writer can escape coverage.** `declare_writer "adminWipe" touches` with no tables is never checked.
- **Unknown tables pass.** Nothing validates `touches "nonexistent_table"`.

The two real entries use `provedWriters`, derived from `routeTable`, which is sensible but unchecked.

**Fix:**
- Derive `covers` from the `Sys` the cited theorem quantifies over (for example `Sys.ofWriters` names, or the model's route table).
- Require declared tables to exist.
- Reject writers that declare no tables.

## Low

- **README:97, cross-request isolation:** "after any sequence of requests by a group of players" is looser than `trace_noninterference`. The theorem excludes requests from outsiders, and the group's view includes the whole session table and `nextGame`. The premise itself is not vacuous (`SameViewC` lets games outside the group differ). The satisfiability witness from 617ecef is conditional: no concrete authenticating request is exhibited.
- **`invariant` edge cases:** a field that simplifies to `True` breaks the generated `holdsB_iff` proof with an obscure error. Fields named `check`, `fields` or `holdsB` clash with generated names.
- **`preserves` and cheating:** it rejects only a `sorry` written directly in its proof. `exact cheat _`, where `cheat` uses `sorry`, and `native_decide` pass at `preserves`. They are caught later by the registry and the axiom audit. Universe-polymorphic decisions fail with "unassigned metavariables".
- **`#check_invariant` messages:** it blames decidability for any elaboration error, and prints "✓ inductive" with an empty world list.
- **`check_readme.sh`** only matches fences written exactly as ```` ```lean ````, and passes with 0 snippets.
- **Registry details:**
  - `invariant`/`preserves` entries don't appear in `#properties`.
  - `nextOrder` can collide across sibling modules, and the sort is not stable.
  - Duplicate claim text is accepted.
- **Decision 0017's verification section:**
  - The free-cell mutation reproduces: removing the check breaks the `preserves` block. But it does not show that `allValid` depends on the domain (H1).
  - The 57/13/9 line counts can't be re-derived: there's no pre-migration commit to compare with.
  - The runtime-test, `gen_evidence`, registry and `sorry` mutations are asserted, with no script or commit recording them.

## Holds up

- **Kernel** (`Sys`, `Ops`, `Store`): reachability, the inductive rules, the operator algebra, `WeakestInductive` (fixpoint equation, greatest), `invariant_iff`, CTIs, and the `ListStore` lift.
- **`uniqueIds` / `freshIds`** use the domain's `playMove_id`/`resign_id`. `uniqueIds_needs_fresh` is a real CTI.
- **`movesGrow`** is a genuine step property built on `playMove_extends`/`resign_extends`.
- **`reads_safe`** via `safe_of_pure_plans` is honest. The list of read operations matches every GET in `routeTable`.
- **`step_view_caller`** preserves one caller's view across a step without needing every player's view to match. This closes the earlier open item.
- **`keyed_replay_after`** is genuine for the proved routes. It rests on receipts only growing and sessions never changing under `Model.step`.
- **`trace_noninterference`** is not vacuous (see Low).
- **`invariant`:**
  - The generated structure matches the fields, and `check` names exactly the failing fields.
  - A non-decidable field gives an error naming it, with the promised remedies.
  - `proof_only` generates only the sound direction.
- **`preserves` (structure carriers):**
  - The statement is exactly `I s → f … s = .ok s' → I s'`.
  - A decision whose accepted branch breaks the invariant fails, with goals tagged by field and branch.
  - It uses only `propext` and `Quot.sound`, and a direct `sorry` or `admit` is refused.
- **`register_property`** refuses `sorryAx` and `native_decide`.
- **`gen_evidence.sh --check`** cannot pass vacuously: missing markers and empty sections are errors.

## Recommended order

1. **H1:** make `allValid` rest on the `preserves` theorems for updates.
2. **H2:** tie `Hidden` and `Enabled` to `acts`, and discharge `ReadsOwn`.
3. **H3, M3:** check every initial world; state the depth bound in messages; check `initB` against `S.init` where decidable.
4. **H4:** require an explicit state argument when it is ambiguous.
5. **H5, M1:** derive `covers` from the cited system; make `unproved` parse and appear in the generated row.
6. **M2, M4:** the `withContext` fix, and naming unnamed constructor arguments in `Enumerate`.
7. **Docs:** README:95 and :97, EVIDENCE:74, decision 0016, PLAN:340, decision 0017's verification section.
8. **Process:** push, and tag `v0.6.0`.
